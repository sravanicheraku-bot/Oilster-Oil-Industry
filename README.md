# Oilster – Oil Industry Data Analysis Using SQL

## 1. Project Overview

The Oilster project focuses on analyzing oil and energy-related data using SQL. The purpose of this project is to understand oil production, consumption, emissions, and their relationship with economic indicators across different countries.

This project demonstrates how SQL can be used to explore datasets, identify patterns, compare country-level performance, and generate meaningful business insights.

## 2. Project Objectives

- Analyze oil and energy consumption across countries.
- Identify countries with the highest and lowest production.
- Compare energy production and consumption.
- Analyze emission patterns across countries.
- Understand the relationship between energy consumption and GDP.
- Generate insights to support data-driven decisions.

## 3. Tools & Technologies

- SQL
- MySQL
- MySQL Workbench

## 4. SQL Concepts Used

- SELECT and WHERE
- Aggregate Functions
- GROUP BY and ORDER BY
- Joins
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Ranking Functions
- LAG()
- Views

## 5. Key Analysis Areas

1. Country-wise production analysis
2. Country-wise consumption analysis
3. Highest and lowest energy consumption
4. Emission analysis
5. GDP and energy consumption comparison
6. Ranking countries based on energy indicators
7. Comparing current and previous records

## 6. Business Value

The analysis helps understand differences in energy production and consumption across countries. It can provide useful insights into energy demand, production patterns, and emission trends.

These insights can support energy planning, resource management, and informed decision-making.
